- Built a MERN-style hotel booking app with separate frontend and backend deployments.
- Added authentication with Clerk, including webhook-based user synchronization.
- Implemented hotel, room, booking, and payment APIs using Express and MongoDB.
- Integrated Stripe Checkout for payments, Cloudinary for image uploads, and Nodemailer for email notifications.
- Built hotel-owner dashboard pages for adding rooms, viewing bookings, and tracking revenue.
